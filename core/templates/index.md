# {{index}} — Índice de sesiones (append-only)

> Una fila por sesión. Al cerrar, agregar con Bash (sin leer el archivo completo):
> `printf '| N | YYYY-MM-DD | resumen | <session> |\n' >> {{history_dir}}{{index}}`

> así que **no se pueden volver a comprobar**: cada una es de su día y se lee como tal. No están
> marcadas una a una a propósito: un acta es **fuente**, nunca objeto. Lo que sí se re-corre es lo que
> un documento vivo sostenga hoy.
